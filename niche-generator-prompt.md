# Niche Generator Prompt

Copy and paste this entire prompt into your AI assistant. Replace the placeholders with your previous outputs.

---

You are a niche selection advisor. Your job is to help me commit to a specific niche for my AI-first company. Be direct, be challenging, and don't let me stay vague.

Here is my Skills Audit:
```
[PASTE YOUR SKILLS AUDIT OUTPUT HERE]
```

Here is my Market Fit Analysis:
```
[PASTE YOUR MARKET FIT ANALYSIS HERE]
```

## Your Task

### Step 1: Generate 5 Niche Candidates

Based on my inputs, generate 5 specific niche statements using this formula:

> "I help [specific audience] [achieve specific outcome] using AI [specific method/approach]."

Each niche should be meaningfully different — not 5 variations of the same idea.

### Step 2: Pressure Test Each Niche

For each of the 5 candidates, evaluate:

| Criteria | Score (1-10) | Notes |
|----------|-------------|-------|
| **Findability** — Can I find 100 of these people in 30 minutes? | | |
| **Urgency** — Would they take a call this week? | | |
| **AI Leverage** — Does AI solve this 10x better? | | |
| **Expertise Match** — Do my skills give me an unfair advantage? | | |
| **Revenue Potential** — Can this generate $10K+/month? | | |
| **Enjoyment** — Would I still want to do this in 6 months? | | |
| **TOTAL** | /60 | |

### Step 3: Recommend

Pick the top 2. For each, give me:

1. **The niche statement** (refined and specific)
2. **First 3 customers to target** — Be specific. What companies? What roles?
3. **The opening message** — What would I say in a cold DM or email to get a conversation?
4. **The 12-week test** — What would prove or disprove this niche in 12 weeks?

### Step 4: Help Me Choose

Ask me 3 gut-check questions to help me decide between the top 2. Things like:
- "If you could only serve one of these audiences for the next year, which one?"
- "Which problem makes you angry that it still exists?"
- "Where do you have the most unfair knowledge?"

Then give me your final recommendation with clear reasoning.

## Output

At the end, produce a clean niche card I can save:

```
## My Niche

**Statement:** I help [audience] [outcome] using AI [method].

**Ideal Customer:** [Title] at [Company Type] ([Size])
**Core Problem:** [The pain in one sentence]
**AI Solution:** [How AI solves it in one sentence]
**Revenue Model:** [How I make money]

**Validation Plan (12 weeks):**
- Week 1-2: [Action]
- Week 3-4: [Action]
- Week 5-8: [Action]
- Week 9-12: [Action]
```

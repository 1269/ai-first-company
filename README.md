# AI-First Company

> A framework for building a tech company with AI at the center — from idea to shipped product, with real projects built in public.

This isn't theory. It's a documented methodology for building software products using AI-native workflows — prototyping in weekends, shipping MVPs in weeks, and marketing before the product is done.

This repo is the open-source companion to my [YouTube channel](https://youtube.com/@jashia), where I build real apps in public and teach the frameworks behind them.

## The GSD Framework

**GSD (Get Shit Done)** is the methodology behind everything in this repo. It's how one person (or a small team) ships real products using AI as a force multiplier.

The core idea: AI doesn't replace your judgment — it accelerates your execution. You still decide what to build and why. AI helps you build it faster, test it sooner, and iterate without burning out.

**Principles:**
- **Ship, don't plan** — A working prototype beats a perfect plan
- **Scope ruthlessly** — Cut everything that isn't essential to the first version
- **Market early** — Start building awareness before the product is done
- **Measure everything** — Set up tracking from day one, not after launch
- **Iterate in public** — Share the real numbers, the real decisions, the real mistakes

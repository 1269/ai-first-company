# Contributing

This is a community project. Your experience building an AI-first company makes it better for everyone.

## How to Contribute

### 1. Share a Prompt

Built a prompt that helped you with a specific business challenge? Add it:

1. Create a `.md` file in the appropriate `prompts/` directory.
2. Include context on when to use it and what it produces.
3. Submit a PR.

### 2. Share an Agent Template

Built an AI agent for your business? Share the config:

1. Create a folder in `agents/examples/[agent-name]/`.
2. Include `README.md`, `system-prompt.md`, and `config.json`.
3. Document what niche it's for and what problem it solves.
4. Submit a PR.

### 3. Write a Guide

Have deep experience with a topic? Write a guide:

1. Create a `.md` file in `guides/`.
2. Keep it practical — frameworks, examples, and templates over theory.
3. Link to related guides where relevant.
4. Submit a PR.

### 4. Improve Existing Content

Found an error, outdated info, or a way to make something clearer?

1. Fork the repo.
2. Make your changes.
3. Submit a PR with a clear description of what changed and why.

## Style Guide

- **Be direct.** No fluff. Respect the reader's time.
- **Be specific.** "I help B2B SaaS companies" beats "I help businesses."
- **Be practical.** Include templates, examples, and actionable steps.
- **Be honest.** If something doesn't work or has tradeoffs, say so.
- **Use markdown.** Keep formatting consistent with existing files.

## What We're Looking For

- Real-world prompts that have been tested, not theoretical ones.
- Agent templates from actual business use cases.
- Guides grounded in experience, not just research.
- Improvements to clarity, accuracy, or usability.

## What We're NOT Looking For

- Promotional content for specific paid tools or services.
- Generic AI hype or motivational content.
- Content that requires proprietary tools to use.
- Anything that doesn't help someone build an AI-first company.

## Code of Conduct

Be helpful. Be honest. Be respectful. We're all building here.

## Questions?

Open an issue or start a discussion. We'll get back to you.
